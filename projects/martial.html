Martial App Backend

Fitness app backend built at Alright Tech, running in production. It powers a martial-arts and fitness app: training programs, member progress, push notifications, and the admin panel that runs it all.

What I did

  • Built training program management: programs and content served to the app.
  • Built user progress tracking: members' training progress recorded and served back to the app.
  • Built push notifications with FCM: alerts and updates delivered to members' devices.
  • Built the admin panel: the backend interface for managing programs, users, and content.

How I built it

  • Laravel backend: programs, progress tracking, and notification logic.
  • MySQL database: users, programs, and progress records.
  • Firebase Cloud Messaging (FCM): push delivery to the app.
  • Built in PhpStorm, my primary IDE.
