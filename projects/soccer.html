Soccer Platform

Sports platform backend built at Alright Tech, running in production. It powers the platform's data — matches, teams, and live information — plus the tooling the team uses to manage it.

What I did

  • Built match and team management: the data and endpoints behind fixtures, teams, and results.
  • Built live data endpoints: REST endpoints that serve live match information to the platform.
  • Built admin tooling: the backend tools for managing platform content and data.

How I built it

  • Laravel backend with REST APIs: structured endpoints for matches, teams, and live data.
  • Vue.js on the platform's interfaces, working with the Laravel backend.
  • Built in PhpStorm, my primary IDE.
